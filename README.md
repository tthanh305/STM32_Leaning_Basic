# 📚 STM32F103 – Thực hành cơ bản

Repository lưu lại quá trình học và thực hành **STM32F103** theo từng buổi.

> 🔧 **Nền tảng:** STM32F103C8T6
> 💻 **Môi trường:** Linux + ARM GCC
> 📖 **Thư viện:** CMSIS / STM32 Standard Peripheral Library
